# 18 · Dashnote 交互与动效规范 v1.0（2026-11-27）

本规范定义 Dashnote 全站及所有车机 HMI 组件（`001` 到 `100`）的交互边界、物理弹簧、形变与微动效标准，与视觉静态规范 [15-card-guideline.md](15-card-guideline.md) 及弹窗转场文档 [09-handoff-sheet-motion.md](09-handoff-sheet-motion.md) 配套使用。

## 1. 总原则

1. **克制与语义优先** 只在真实存在交互意图或状态变化的地方加动效。纯信息展示组件与只读数据块（如 `001 Turn-by-turn panel`、`010 Result row`、`011 Tire pressure`、`021 Navigation search`、`022 Driver alert`、`023 Hands-on alert` 以及 `026 Scheduled charging` 中的 `Start / End` 时间展示区）绝不伪造点击态、缩放反馈或多余入场动效，避免误导驾驶者。
2. **下击反馈与丝滑节奏** 可点击控件统一采用舒缓利落的下击缩小（`90–100 ms`，`cubic-bezier(.2, 0, 0, 1)`，小图标约 `scale(.90)`、中按钮约 `scale(.94–.96)`、大卡片约 `scale(.97–.982)`），抬起后用丝滑弹性曲线（`380–420 ms`，`cubic-bezier(.22, 1.12, .36, 1)`）柔和回弹恢复原尺寸。
3. **无抖动、无冗余重播** 图标与状态文字不允许无意义的来回晃动、上下弹跳或持续呼吸；切歌歌名与歌手名采用纯透明度交叉切换（无上下位移）；增删单个字符时只动发生变化的单个字符，不把整段已存在文字重新动画一遍。
4. **单线程合成与降级** 所有连续位移动画走 compositor 合成层（`transform` / `opacity` / `filter` / `@property` 遮罩），不在高频计时器里反复重写 `innerHTML`，并完整遵守 `prefers-reduced-motion: reduce`。

## 2. 六类核心动效原语

### 2.1 分段控件、侧栏与路线卡移动指示器（参考 DriveScene Studio `ui-motion.js`）
适用于左侧栏导航 `#navind`、详情顶栏 `After / Before`（`#seg4`）、`002 Route selection` 三张路线卡（竖向 `.rs-ind`）以及 `007 Locks`、`014 Parking method`、`016 Energy use`、`027 Display brightness` 全部水平分段控件。

- **物理机制** 前后双边缘独立有界弹簧（`boundedSpring`，`ARC_MOTION_SCALE = 0.64`，`MORPH_STRENGTH = 1.2`，`damping = 0.84`）。前进边缘先启动（`visualDuration = 0.26`），尾部边缘稍晚追上（`0.26 + 0.16 * 1.2`），在移动中段形成自然的轴向拉伸与轻微垂直压缩，落位后平滑收束。
- **形变强度** 水平分段控件 `CONTROL_MORPH_SCALE = 0.85`，竖向侧栏与 `002` 路线选中卡 `NAV_MORPH_SCALE = 0.476`，总时长 `320 ms`（`500 * 0.64`），指示器必须设 `transform-origin: 0 0`。
- **解耦约束** `027 Display brightness` 顶部的模式分段控件（`Auto / Day / Night`）与底部 `Brightness` 滑块完全解耦，切换模式不联动修改亮度数值。

### 2.2 开关滑块（Toggle）移动与中段微形变
适用于 `005 Update settings`（`80 × 48`，位移 `32 px`）、`007 Locks`（`60 × 32`，位移 `28 px`）、`026 Scheduled charging`（`80 × 48`，位移 `32 px`）。

- **物理机制** 独立实心滑块 `.sw-k` 驱动位移弹簧（`260 ms`，`visualDuration = 0.24`），形变包络直接绑定瞬时速度与路程正弦门控 `(|speed| / maxSpeed) * sin(π * u)`，确保形变**仅发生在中段滑行过程中**、落位前即完全恢复正圆（杜绝结尾发软形变），幅度克制在横向最大 `+11%`、纵向 `-4.8%`。
- **排错约束** 禁止让后置样式的 `left` 覆盖 `.sw.off` 规则；静态兜底与交互实心滑块必须同步位移。

### 2.3 图标面性 ↔ 线性径向切换（参考 Dashline `revealVariant`）
适用于 `003 Place details` 右上角收藏书签及后续需要面性/线性切换的图标。

- **物理机制** 注册 `@property --vr` 长度变量，双层同轮廓 SVG 叠放，使用按面积匀速推进的缓动曲线（`BM_REVEAL_EASE`，`340 ms`），从图标几何中心（`24px 24px`）向外扩张软边径向遮罩（羽化 `8 px`）完成面性铺开或中心镂空切回线性，同时配合轻微弹性缩放（`0.92 → 1.07 → 1`），严禁双边重影闪烁。

### 2.4 几何路径形变、方向推进与粒子反馈（`024 Mini player`）
- **Play ↔ Pause** 同结构双半片 SVG 路径丝滑弹簧插值（`stiffness = 320`，`damping = 26`，约 `320 ms` 柔和弹性收束）。几何进度严格钳位在 `[0, 1]` 且在播放态合并右侧重复顶点为三点三角，杜绝过冲导致的右侧尖端自交小圆，过冲呼吸仅作用于整枚 SVG 的微幅缩放。
- **上一首 / 下一首** 严禁左右抖动。点击时原三角形沿方向滑入竖杠并缩小淡出（`280 ms`），同时新三角形在裁切窗口内从反方向滑出补位（`340 ms`，延迟 `50 ms`，丝滑轻弹性），竖杠同步做轻微纵向弹跳（`scaleY 1 → 1.13 → 1`，`320 ms`）。
- **曲目切换** 仅支持 3 首曲目循环（`Horizon`、`Night Drive`、`Glass Roads`），3 张同风格丝绸光感封面以 `360 ms` 交叉淡入淡出，歌名与歌手名仅做纯透明度切换（`140 ms` 淡出 + `260 ms` 淡入），不做任何上下位移。
- **点赞收藏（心形）** 点亮时心形做丝滑弹性缩放（`0.76 → 1.22 → 0.96 → 1`，`440 ms`），同时从中心迸发 1 圈柔光扩环（`400 ms`）与 8 枚克制微粒子（`460–540 ms`）；取消收藏时轻柔缩回不放粒子。

### 2.5 双态落点波纹扩散（Pointer-Origin Dual-Mode Ripple）
按控件点击后是否切换底色分为两类波纹原语，均按 `.px` 舞台缩放比例换算精确落点坐标：

- **模式 A · 不变色瞬时按键（中性柔色波纹，`640 ms`）** 适用于 `009 Search keyboard`、`012 Dial pad`、`002` 底部双按钮、`003` 主按钮、`008` 对话框按钮、`013` 编辑键、`014` 底部双按钮、`026` 编辑键。点击后从落点平缓扩散淡淡的中性灰/透白光晕（`640 ms`，`cubic-bezier(.22, 1, .36, 1)`），克制舒缓、不刺眼。
- **模式 B · 变色开关磁贴与标签（目标色 / 默认色径向铺色，`520–580 ms`）** 适用于 `015 Drive modes`、`006 Opening tiles`、`003` 标签胶囊、`026` 星期芯片。底色冻结严格挂在独立 `.dn-wash-layer`（绝不写内联 `el.style.backgroundColor`，杜绝连续快点污染 `getComputedStyle` 导致黑字蓝底）；内描边独立绘制在 `::after` 顶层（`z-index: 2`），避免波纹收尾时描边突闪；快速连续点击打断未完成波纹时，立即冻结上一圈扩散并在 `<= 300 ms` 内柔和淡出，同时从新落点顺畅铺开新一圈目标色波纹，文字与图标颜色（同步显式 `filter` 基线）以及带版本令牌保护的 `OFF / ON` 模糊切字始终与目标态严格一致。
- **拨号数字输入（`012`）** 上方号码区每个字符独立成 `<span>`，输入时仅对新追加的末尾字符做轻快显现（`140 ms`），删除时仅淡出末尾字符（`95 ms`），已存在数字完全静止不动。

### 2.6 状态显隐、展开收起、蓝底激活与计时器
- **`001 Turn-by-turn panel`** 纯信息展示，完全静态，无点击响应、无入场动效。
- **`013 Multi-stop itinerary`** 拦截原生 `<details>` 硬切。收起时外框高度平滑收缩（`340 ms`），同时内部 `.it-body` 向上轻移并叠加模糊淡出（`blur(0 → 5px)`，`translateY(-14px)`，`220 ms`）；展开时高度平滑撑开（`360 ms`），内容从微模糊平滑清晰显现，右侧箭头同步旋转（`360 ms`）。
- **`025 Call banner`** 整体宽度与按钮槽位仅在 `Incoming`（`660 px`）与 `On call`（`828 px`）两态间做丝滑弹簧形变（`540 ms` / `520 ms`），彻底移除不合逻辑的 `Calling` 挂断动画态（来电态点击红色拒接键不触发假挂断形变，通话中点击红色挂断键复位回 `Incoming` 便于复玩）；右侧状态文案（`Incoming` / `On call`）在竖向分割线与右缘之间严格水平居中（`justify-content: center`，左右等距 `20 px`），原地静默模糊切换（`280 ms`）；计时器采用 4 列纯 GPU 合成纵滚数字滚轮 `.tm-reel`（`0–9–0` 预渲染叠加软边上下遮罩，纯 `translate3d` `380 ms` 平滑滚动，零 DOM 重写、零模糊重栅格化，彻底杜绝每秒一蹦一蹦的卡顿）；静音与听筒圆形按钮变色采用 `::before` 实心圆从中心丝滑放大铺满（`340 ms`），静音斜杠划出（`260 ms`）。
- **`006 Opening tiles` 与 `015 Drive modes`** 点击开启（`is-open` / `aria-pressed="true"`）时，整张磁贴统一切换为主色蓝底（`var(--pri)` / `var(--vehicle-action)`）、主色描边与纯白图标文字（`#fff`），不使用仅描边的高亮样式。
