## 2026-11-19

**做懂车机规范的 MCP（v0.1 已完成）**
- 原因：AI 不懂车机规范，生成的都是手机 App 风格。MockFlow 的车机技能试过，效果不好。
- 内容：79 条规则、白天/夜间 token、40 个组件索引、布局检查器。零依赖。
- 定位：卖"车机知识 + 检查"，不卖"长相"。车企有自己的组件库，可以自带风格，用我们的规则层。

**北美方向：Android Automotive 为第一优先平台，但不唯一**
- GM、Ford、Volvo 等在用；Unreal 也在大量车型上用；Tesla、Rivian 自研。
- AAOS 上第三方 App 开发者只能用模板、改两个强调色，几乎没有设计空间；真正能改 UI 的是车企和设计公司。

**定位参考：车企版的 Vercel Geist / Arc UI**
- 后来进一步收窄为"实践手册"，见 2026-11-22。

**网站结构经历过一次反复**
- 试过"左右分割的车机式网页"，被否定：网页没有这样的布局，太简单。回到常规网站结构。
- 视觉参考 Dashline 网站：侧栏分类 + 分组网格 + 详情弹窗，无负字距，无装饰小字。
