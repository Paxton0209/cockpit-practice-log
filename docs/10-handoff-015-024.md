## The look (applies to every After)

All values come from the Figma file **UI/UX Library** (`qiPTH6OH2yigVKfIavhQbI`). Use its components and variables; never hard-code a value that has a variable.

| | Value |
|---|---|
| Font | Inter. Medium for text, Semi Bold only for the one hero number |
| Sizes (size / line) | caption 24/32 · body 28/36 or 28/40 · title 32/44 · number 48/56 · label 20/28. Nothing under 20 |
| Text colour | foreground `#1D1D1F` (dark `#FFFFFF`); muted 65% (dark 60%) |
| Spacing | 4 · 8 · 12 · 16 · 20 · 24 · 28 · 40 |
| Radius | control 12 · tile 16 · inner 20 · panel 24 · full 999 |
| Targets | 68 px hit area minimum; rows 76 (settings) or 100 (lists in nav panels); main buttons 68 tall |
| Icons | 48 px frame, stroke 3 in headers, 2 elsewhere; one colour (currentColor) plus the `branch` grey where the library uses it |
| Accent | primary `#007AFF` (dark `#0C6FD2`) with a 2 px inside edge `#409CFF` (dark `#0A84FF`). One primary action per component |
| Surfaces | floating panel: white 65% + 6 px background blur + 2 px inside border `#1D1D1F` 5% + shadow 0 8 16 `rgba(28,28,46,.18)`. Settings card: the library's `list-card` |
| Status colours | warning `#FF9F0A`, critical `#FF3B30`. Only on the one thing that needs attention, never as decoration |

The ten rules every After follows:

1. One job per component. If it needs a paragraph to explain, it's two components.
2. The thing read at a glance is the biggest thing. Labels and units step back (65%).
3. No labels on numbers that explain themselves. No all-caps. No filler words.
4. Choices with 4 or fewer options are shown flat (segmented control), never a dropdown.
5. Colour only for state that needs attention. One accent fill per component.
6. Targets ≥ 68 px; main actions sit on the bottom edge or next to what they act on.
7. Light and dark are the same layout with the file's dark variables. No pure white surfaces in dark.
8. Strokes are inside (Figma "inside" = CSS inset box-shadow), so they never change the size.
9. Copy is plain English, sentence case, as short as it can be.
10. Match the library first. A new component reuses existing parts (rows, chips, segments, buttons) before inventing one.
