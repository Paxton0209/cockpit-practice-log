# 17 · Design Reference 审美抽取与结构解构（2026-11-26）

本文件对应 Figma 独立参考文件 `Design-Reference`（`fileKey = 03WCJvxtvD1HO1NtT68D02`，主画布 `Page 2` `1021:22`，共 24 张参考图，包含已归类的 4 个分区 18 张图与右侧新增未归类的 6 张图），用于沉淀个人审美基因、拆解参考页面的可用结构，并明确未来在 Dashnote 网站、工具产品、海外内容与车机 HMI 中的复用边界。早期简版索引见 [06-reference-board.md](06-reference-board.md)。

## 1. 文件架构建议（不合并进 `Guideline`）

建议继续保持 **三文件分离**，不要把 `Design-Reference` 合并进 `Guideline`。

| 文件 | 定位 | 内容性质 | 更新频率与生命周期 |
|---|---|---|---|
| `UI-UX-Library` | 生产组件库 | 唯一主组件、真实变量、样式表 | 随组件打磨稳定迭代 |
| `Guideline` | 车机 HMI 规范 | 强约束规则（Must / Should）、数值基准、色字尺寸规范 | 高度克制、可对外展示或开源 |
| `Design-Reference` | 视觉灵感库 | Web、品牌、SaaS 工具、排版与质感截屏（含反例） | 高频自由收集、随时增删 |

不合并的三个现实原因如下。

1. **领域与约束力不同**。`Guideline` 里每一页都是面向车机大屏的量产规范，而 `Design-Reference` 里超过九成是 Web 站点、开发工具、品牌页与内容平台的视觉参考，里面还包含专门记录反例的 `04 Not for us`。混在一起会模糊“灵感参考”和“执行规范”的边界。
2. **文件性能与维护成本**。参考板会不断堆叠高分辨率位图（当前单张多在 `1361×1701` 到 `2336×1911`），放进 `Guideline` 会拖慢日常查规范、开变量和切模式的加载速度。
3. **沉淀方式更干净**。正确的工作流是在 `Design-Reference` 里持续收集原图与简短批注，定期把真正吸收进系统的结构与规则抽取到 `docs/` 文档或 `Guideline` 的正式规范页里，只沉淀结论，不搬运截屏。

## 2. 审美基因抽取（你的 6 条核心偏好）

横看全部 24 张参考图（含最新放入右侧的 6 张），你的审美取向非常稳定，几乎没有自相矛盾的地方，核心可以提炼为 6 条。

1. **结构说话，拒绝装饰**。偏爱瑞士网格与建筑制图感，`1 px` 极细分割线、编号标签（`[SEC-01]`、`03/06`）、网格交点锚点（小圆点或 Figma 选框角点）本身就是视觉语言，不需要靠插画、贴纸或复杂背景撑场面。
2. **黑白灰双色排版，靠明度拉层级**。强调重点不靠换亮色、不靠加粗到发糊，而是同一句话或同一组步骤里用纯黑（`#111`）和中性灰（`#777`）拉开前景与背景，例如 `AI Fleet` 两行双色标题、`Mortise` 和 `NovaGrid` 的句内高亮、以及步骤列表的“当前项黑、其余项灰”。
3. **九成中性底色配一处克制强调色**。画布长期锁定在纯白、浅灰槽（`#F5F5F7`）与深炭灰之间，最多只留一个功能色或极小面积的语义色。大面积彩虹渐变、炫彩 3D 标志被你明确归进 `04 Not for us`。
4. **“托盘套白卡”的克制景深**。比起强投影或夸张拟态，你明显更喜欢浅灰外槽托着纯白内卡、配 `1 px` 细描边与极轻贴地影的层次（例如 `6345323` 的灰槽配底部状态条、`Attio Blocks` 浮窗、`Twombly` 柔和背景上的安静应用窗）。
5. **质感必须克制且带信息感**。接受单层黑白半调/抖动纹理（`Untitled UI`）、带数据含义的文字纹理（`Feldar`）、或高度虚化的光影色块（`NovaGrid`、`Launchtree`），排斥具象杂乱摄影和人物大头照（人物照会让工具产品显得像个人作品集或营销落地页）。
6. **低噪音微工具体验**。喜欢安静、清晰、密度恰到好处的专业软件界面（`Canvas UI` 文档、`Claude` 极简侧栏、`Attio` 积木选择器），交互热区与状态反馈明确但从不喧宾夺主。

### 分区 `04 Not for us`（明确避坑，1 张 + 文档记录）

- 多彩渐变立体图标与强装饰品牌标（`6345321`）会破坏中性克制底色。
- 人物肖像与传统客户见证栏（`image 16`、`6345322` 右侧）会让产品显得像外包工作室或个人简历页。
- 高饱和大面积暖橙底色（`6345332` 外框）仅适合做偶发的社媒宣发实验，绝不带入车机界面或 Dashnote 主阅读区。

## 4. 未来可直接复用的结构清单（按场景落地）

### A. Dashnote 官网演进（30+ 条目与 V2 改版）

1. **首页 Bento 升级（借鉴 `Launchtree` `6345334`）**。等条目积累到 30 条以上时，把最新一期或精选条目放大成跨两列的横向主卡（左大尺寸交互预览，右上方标题与编号、下方两行核心原则、中间大留白），搭配顶部的极简章节 Tab 和右侧胶囊搜索框。
2. **网格交点锚点与句内双色标题（借鉴 `NovaGrid` `6345333` + `Mortise` `6345331`）**。在官网章节导语或底栏加入 `1 px` 网格与极小的中性灰/主题蓝交叉锚点，核心理念文案用“句内黑白双色高亮”让读者 1 秒扫出重点。
3. **硬核数据指标角标（借鉴 `NovaGrid` `99.20%` + `AI Fleet`）**。在详情弹窗的评测区或封面展示 `99.1% Match`、`≤ 2.0s Glance` 这类量化数据，整数纯黑/纯白高亮、小数与单位适度退灰，立刻拉高专业信任感。
4. **章节诊断页（借鉴 `The Problem` `6345314`）**。每个大章（Navigation、Settings、Voice & AI）都可以加一个顶部导览块，用 3 张微界面卡片直观列出“AI 做这一类车机界面最常踩的 3 个坑”。

### B. 互动工具、插件与后续商业化产品

1. **快速选择器与积木面板（借鉴 `Attio Blocks` `6345329/30`）**。这套结构几乎可以直接照搬成 Dashnote 的 `Cmd+K` 组件快搜面板、或未来 Figma 插件里的“按模块插入/复制 Prompt”悬浮器，顶部搜索 + 分组折叠 + 左侧低饱和分类色块小图标 + hover 细框与右侧 `+` 动作，极度契合你的极简克制审美。
2. **灰槽嵌套卡（借鉴 `6345323`）**。继续统一用在 Prompt 复制框、Token JSON 预览与未来 `MCP` 接入代码片段上，底部灰条固定放实测状态和主按钮。
3. **暖调深色付费页（借鉴 `6345326`）**。以后推出提示词合集、Figma 完整库或作品集模板时，直接采用深炭双栏卡片配顶部一层单色 dither 柔光，不需要做成俗套的亮色 SaaS 定价表。

### C. 海外社媒与 10 秒短视频（X / LinkedIn / YouTube）

1. **句内黑白双色金句卡（借鉴 `Mortise` `6345332`）**。日常发轻量化观点帖（每周 2 条过程感悟）时，直接做成纯白网格底 + 句内灰黑双色对比的单图卡，配一个极小 Figma 角标框标出主题词（如 `Glance Budget`、`Optical Alignment`），零门槛且视觉系列感极强。
2. **柔和动态光影底图（借鉴 `NovaGrid` `6345333`）**。100 条 10 秒短视频每条要换不同背景，除了现有建筑材质底纹，可以加入一批极低饱和的柔和动态模糊光影背景，既清爽又不抢车机组件主体的清晰度。

### D. 车机 HMI 与 `Guideline`（只取底层逻辑，不搬 Web 装饰）

- **可以吸收**。双色明度分层（已落地为 `text/primary` 与 `text/secondary`）、超大数字配极小单位标签（仪表/能耗/距离）、以及 `Attio Blocks` 里用极浅语义底托配线性图标区分大类的思路（适合车机设置或 AI 快捷指令分组，前提是放大到车机 `48 px` 画板并满足 3 比 1 对比度）。
- **明确隔离**。`1 px` 网格十字锚点、Figma 选框角点标签、衬线字体、全屏高饱和信号橙和大面积半调颗粒纹理都只停留在 Web 与品牌层，绝不进入车机屏幕。
